# cowriter 使用指南

> 面向使用者的操作手册：装好之后怎么用、命令怎么打、人机双写怎么协作。
> 产品定位与设计取舍见 [README](../README.md)；插件接入见
> [plugin-integration.md](plugin-integration.md)。

## 1. 安装与启动

需要先装 [Dart SDK](https://dart.dev/get-dart) 3.6+（`dart --version` 确认）。

```bash
git clone https://github.com/Fi2zz/cowriter.git
cd cowriter
dart pub get
dart run bin/cowriter.dart
```

**在你的文稿目录里启动**：cowriter 把当前目录当工作区（沙箱根）。`cd cowriter` 只是
为了跑源码；真正要写作时请 `cd /你的/文稿/目录` 再运行，或在 config.toml 设
`[agent] workdir = "/你的/文稿/目录"`。

打包成自包含可执行文件（目标机器不需要 Dart SDK）：

```bash
bash tool/build_binary.sh          # 产出 dist/cowriter
ln -s "$PWD/dist/cowriter" /usr/local/bin/cowriter
```

## 2. 命令行参数

| 参数 | 说明 |
|------|------|
| `--session <id>` | 打开/恢复指定会话；id 必须是 `session_<uuid>` 规范格式，否则视为新建会话 |
| `--continue` | 恢复最近一次会话（`--session` 优先于它） |
| `--config <路径>` | 配置文件路径（缺省 `~/.nava_cowriter/config.toml`） |
| `-p, --print <任务>` | headless 单轮执行，跑完即退出（不启动 TUI） |
| `--output-format text\|json` | headless 输出格式（缺省 `text`） |
| `--allow-unsafe-headless` | 允许 headless 在 OS 沙箱关闭时启动（危险，见 §9） |
| `--version` | 打印版本号后退出 |
| `-h, --help` | 打印用法后退出 |

环境变量 `COWRITER_HOME` 可覆盖配置目录（缺省 `$HOME/.nava_cowriter`）。

## 3. 模型配置

首次运行会生成配置模板并弹出 provider 面板。最小配置：

```toml
[providers.ark]
api_key = "ark-..."
base_url = "https://ark.cn-beijing.volces.com/api/v3"
type = "openai"        # openai → chat/completions；kimi → responses

[llm]
default_model = "ark/doubao-seed-1-8-251228"   # provider/model
# fallback_models = ["deepseek/deepseek-chat"] # 主模型失败后的回退链
```

- Key 解析顺序：`[providers.<名>] api_key` → `[providers.<名>] credential_key`
  指向的凭据（环境变量 / `[credentials]` 表）→ 注入的凭据服务（缺省环境变量）。
- Plan 端点只认订阅后生成的专属 Key：provider 名自定（如 `arkcli-agent-plan`）、
  `base_url` 用 `.../api/plan/v3`、Key 用 `ARK_AGENT_PLAN_API_KEY`；普通方舟
  Key（`ARK_API_KEY`）打 plan 端点会返回 401。内置预设 `volcengine-coding-plan`
  （`.../api/coding/v3`）对应 `ARK_CODING_PLAN_API_KEY`。
- 会话内用 `/provider` 增删、`/model` 切换，都会写回 config.toml。

## 4. 斜杠命令总表

会话内输入 `/` 弹出命令菜单；`Esc` 关闭面板。

| 命令 | 说明 |
|------|------|
| `/help` | 显示帮助（与 `/` 菜单同一份数据） |
| `/new` | 开启新会话（上一会话已保存） |
| `/session <id>` | 切换或新建会话（id 即数据文件名） |
| `/sessions` | 打开会话选择面板（↑↓ 选择，Enter 切换） |
| `/tools` | 列出当前已注册的工具 |
| `/mcp` | 列出已接入的 MCP server（就绪状态 / 工具数） |
| `/model` | 打开模型选择浮层（搜索过滤，Enter 切换） |
| `/provider` | 提供商管理浮层（add 导入 / `<名字>` 切换 / remove 删除） |
| `/permission` | 权限模式选择面板（始终询问 / 按需询问 / 从不询问） |
| `/plan` | 进入 / 退出 Plan Mode（先规划，经 exit_plan_mode 提交后执行） |
| `/goal <子命令>` | 长期目标：`status` / `set` / `edit` / `pause` / `resume` / `done` / `clear` |
| `/init` | 让模型扫描仓库生成 `AGENTS.md`（已存在则更新） |
| `/compact` | 手动压缩当前会话（折叠早期历史） |
| `/story [子命令]` | 故事线：时间轴 / `preview <n>` / `discard <n>` / `fork <n>` / `pending` / `apply <i>` / `reject <i>` |
| `/rewind [N\|list]` | 回滚工作区到 N 轮前（缺省 1）；`list` 查看可用检查点 |
| `/background <子命令>` | 后台任务：`list` / `output <id>` / `kill <id>` |
| `/doctor` | 体检：配置 / 提供商 / 沙箱 / 工具 / rg |
| `/cost` | 展示今日估算成本与 token 用量 |
| `/cron <子命令>` | 定时任务：`list` / `add <内容> <at\|every\|daily\|cron> <规则>` / `remove <id>` / `enable <id>` / `disable <id>` / `history [条数]` |
| `/remember <内容>` | 直接记住一段信息（不经模型） |
| `/forget <id 或 关键字>` | 直接遗忘记忆（不经模型） |
| `/telemetry` | 显示最近的可观测性事件 |
| `/trace [轮数]` | 复盘最近 N 轮（缺省 1）：模型看到了什么、调了什么、哪里失败 |
| `/export [路径]` | 导出当前会话为 markdown（缺省落项目数据目录 `exports/`） |
| `/team <子命令>` | 进入团队视图；`status` 摘要 / `interrupt <成员 id>` 中断 |
| `/task <子命令>` | 任务板：`claim <任务 id>` / `release <任务 id>` |
| `/clear` | 清空屏上记录（不改动会话数据） |
| `/exit` | 退出并关闭 TUI（同 `/quit`、`Ctrl+C`） |
| `/skill:<技能名> [补充要求]` | 手动触发一个技能（技能正文展开成一轮用户输入） |

## 5. 键盘与鼠标

| 按键 | 行为 |
|------|------|
| `Enter` | 发送；busy 时自动排队（上限 20 条） |
| `Esc` | 打断当前轮次（在跑的子 Agent 一并取消）；关闭面板 / 视图 |
| `Ctrl+T` | 对话视图下展开 / 折叠 TODO 列表；团队视图下返回对话 |
| `Ctrl+O` | 展开 / 收起最近一条可折叠详情（工具结果 / 思考） |
| `Ctrl+V` | 粘贴：系统剪贴板图片（macOS）或文本里的文件路径，成为附件 |
| `Backspace` | 移除输入栏上的附件 chip |
| `Ctrl+C` / `⌥C` | 有选区时复制；无选区连按两次退出 |
| `!`（空提示符） | 进入 shell 模式（一次性；`Esc` 退出不执行） |

- 鼠标选中即自动复制到系统剪贴板（macOS）。
- `!<命令>` 直接执行 shell 命令，不进模型、不烧 token；`!!` 重跑上一条。

## 6. 人机双写工作流

cowriter 的核心是「两个人对同一份文档打补丁」。一轮典型协同：

```
1. 你提出要求
   你 › 把这段开头的语气改得直接一些

2. AI 编辑被拦成待定补丁（交互模式）
   AI › （edit_file）→ 已登记为待定补丁 #1，待人审阅生效

3. 你审阅并决定
   /story            # 看时间轴：哪些补丁、谁写的、落在什么文件
   /story pending    # 看待定：序号 + 来源 + ops 摘要
   /story apply 1    # 接受，写盘并入故事线
   /story reject 1   # 丢弃，文件原样不动

4. 或者你自己动手改
   在编辑器里改完文件 → watcher 登记为「人」的补丁
   → AI 下一轮收到通报「你改了 X（+3/-1 行）」，可 read_file 看细节
```

四个动作对应四种补丁操作：**接受**（apply）、**拒绝**（reject）、**自己改**
（人的补丁自动入故事）、**回退**（`/story discard` 或 `/rewind`）。

> 先厘清两个词：**一轮** = 你的一次提交到模型收口（空闲 2 分钟自动划分新一轮）；
> **一步** = 一轮内模型循环一次（一次请求 + 工具执行），上限 `[agent] max_steps`。
> 两个序号也别混：`apply` / `reject` 用**待定序号**（`/story pending` 里的 1、2、3），
> `discard` / `preview` / `fork` 用**时间轴序号**（`/story` 列表里的 1、2、3）。

- **想丢掉还没落盘的改动**：`/story reject <i>` —— 待定补丁作废，文件原样不动。
  （AI 的编辑默认先成待定补丁，所以「AI 改了但我不想留」通常用这个。）
- **想回退已入时间轴的改动**：`/story discard <n>` —— 驳回第 n 个补丁，把触及
  文件写回 fold 后内容；若该文件在 fold 后已消失，保守保留不删。
- **想开一条草稿线**：`/story fork <n>` —— 从前 n 个补丁分叉一个新会话并切过去，
  旧会话完整保留。
- **想让 AI 只提议不落盘**：它也可以用 ```` ```ops ```` 围栏块提议（第二通道），
  同样经 `/story apply` 才生效。
- **冲突处理**：若你在 AI 待定期间又改了同一文件，`apply` 会写一份双版本合并文本
  （人的版本在上、AI 待定内容在下），等你人工合并，不覆盖不静默失败。

完整机制与 v1 边界见 README 的[人机双写故事层](../README.md#人机双写故事层)。

## 8. headless 用法

```bash
# 单轮执行，文本输出
cowriter -p "把 README 的安装一节改得更短"

# JSON 输出，便于脚本消费
cowriter -p "总结这个仓库的结构" --output-format json

# 恢复指定会话后继续
cowriter -p "接着上一条继续" --session session_<uuid>
```

headless 的退出码：`0` 成功、`1` 轮次失败、`2` 配置错误或安全闸门拒绝。

## 9. 安全姿态

- **交互模式**：高危工具（`high` 风险）走审批；默认叠加两层沙箱——Layer 1
  应用层文件 jail（任何平台），Layer 2 OS 级进程沙箱（仅 macOS）。
- **headless**：不装审批链（无人可应答），**安全兜底只剩 OS 沙箱**。因此
  `[sandbox] enabled = false` 或 `preset = "danger_full_access"` 时 headless
  拒绝启动（退出码 2）；确知风险要强行启动需显式 `--allow-unsafe-headless`。
- 未声明风险的 MCP 工具缺省提级 `high`（stdio 子进程不经本地沙箱，审批是
  唯一防线）。
- `[hooks]` 命令经 `/bin/sh -c` **直连**运行，不经沙箱——权限等于你本人，
  只挂你信任的脚本。

## 10. 排查

| 现象 | 先看 |
|------|------|
| 模型调用报 401 / 缺 Key | `/doctor` 的提供商与回退链；`/provider` 检查 base_url / api_key |
| 命令执行被禁用 | `/doctor` 沙箱项；非 macOS 需显式 `[sandbox] enabled = false` |
| 工具没出现 | `/tools` 看工具表；MCP 工具看 `/mcp` 是否就绪 |
| 改了文件 AI 没反应 | `/story` 看人的补丁是否已登记；通报在 AI 下一次请求前注入 |
| 编辑没落盘 | `/story pending` 看是否被拦成待定补丁；`/story apply <i>` 接受 |
| 想回退又不想丢对话 | `/story discard <n>`（只回退文档）vs `/rewind [N]`（文件 + 对话一起回退） |
| 模型答得不对怎么复盘 | `/trace [轮数]` 看它当时看到了什么 |
| 不知道花了多少 | `/cost`（真实费率，查不到明说「未知」） |
